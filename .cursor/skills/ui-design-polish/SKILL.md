# UI design polish

## Core brief (verbatim)

suppose you are professional ui  and UE designer, ple give it a better design -- easy to use and more clean and beautiful.

And make it align with other page too.

## How to apply it

1. **Establish patterns first** — Before proposing or implementing changes, read the current screen’s layout and shared styles (for example `application.css`, layout templates, and nearby views/controllers for sibling routes). Match typography scale, spacing rhythm, color tokens, borders, and component patterns already used elsewhere.
2. **Prioritize usability** — Reduce cognitive load: clear hierarchy, predictable interactions, sufficient tap/click targets, readable contrast, and obvious primary actions.
3. **Clean and beautiful** — Prefer restraint: consistent whitespace, aligned grids, one clear focal area per view, and subtle motion or decoration only when it aids understanding.
4. **Cross-page alignment** — Reuse existing partials, utility classes, and naming; avoid one-off styling that contradicts other pages unless the user asks for a deliberate break from the system.

## Deliverables

When implementing, produce cohesive markup/CSS (or framework equivalents) that fits the project’s existing conventions, not a disconnected redesign.
